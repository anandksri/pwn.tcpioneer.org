# Security Policy

PWN TCPioneer handles authentication, user accounts, OAuth integrations, and password-related workflows, so security reports are welcome.

## Reporting a Vulnerability

Please report vulnerabilities privately rather than opening a public issue.

Include:

- A clear description of the vulnerability
- Steps to reproduce it safely
- The affected endpoint, feature, or component
- Security impact and realistic abuse scenarios
- A minimal proof of concept when useful

Do not include real credentials, tokens, personal data, or production secrets in a report.

## Responsible Disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing technical details.

## Scope

This policy covers the application code and security-relevant configuration maintained in this repository.
